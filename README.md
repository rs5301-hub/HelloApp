# HelloApp

## Overview
HelloApp is a simple Java application designed to demonstrate a structured software development workflow using Git and GitHub. The project prints basic messages and will gradually implement different use cases.

## Purpose
The purpose of this project is to:
- Practice GitHub repository management
- Understand branching strategies
- Implement application features using use cases
